# StudyMate — Project Description

## 1. Problem Statement

Students often struggle with difficult topics because explanations may be too advanced, too long, or not adapted to their level. They may also use separate platforms for explanations, notes, quizzes, and planning.

## 2. Proposed Solution

StudyMate is an AI-powered learning companion that gives students four connected learning actions:

- Explain a topic in simple language
- Convert a topic into exam-friendly notes
- Generate a practice quiz
- Create a 7-day study plan

The student chooses a learning level, enters a topic, and receives an AI-generated response.

## 3. AI Component

The MVP uses the Gemini API from a secure Node.js backend. The API key is stored in an environment variable instead of the browser.

## 4. Innovation

The main idea is not only "ask AI a question." StudyMate turns one topic into a mini learning loop:

Learn → Revise → Practice → Plan

## 5. Target Users

- School students
- College students
- Beginners learning technical subjects
- Students preparing for exams

## 6. Example User Journey

A student enters "Binary Search Tree" at Beginner level.

1. StudyMate explains BST step-by-step.
2. The student switches to Make Notes.
3. StudyMate creates concise revision notes.
4. The student switches to Take Quiz.
5. StudyMate generates MCQs.
6. The score is saved locally.
7. The student can create a 7-day plan for further practice.

## 7. Expected Impact

StudyMate can reduce the friction between understanding a concept and practicing it. It provides a single learning workflow that is simple enough for beginners.
